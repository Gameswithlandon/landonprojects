1. The Service

Synapse is a hub-and-spoke staff bot. A public community server is a Spoke. A private staff server is a Hub. Standalone mode uses one server as both. Spoke traffic is routed to the Hub triage channel, and staff actions taken in the Hub are applied back in the Spoke. Hub administrators approve or deny Spoke link requests. A 6-character link code identifies the Hub. Rotating that code does not disconnect Spokes that are already linked.

Synapse runs only through slash commands, modals, and message components. It does not request or use Discord’s Message Content intent, and it does not read the text of ordinary chat messages.
